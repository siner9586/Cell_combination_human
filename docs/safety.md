# 安全边界说明

本项目仅用于教育性、抽象化、非操作性的科学可视化。

## 明确不包含

- 真实实验流程、培养条件、温度、时间、试剂配方；
- 基因序列、gRNA、载体构建、转染/转导步骤；
- 克隆、人胚胎操作、人体制造、胚胎培养或任何可执行生物工程路线；
- 生物样本获取、扩增、筛选、验证等湿实验方法。

## 表达原则

视频中的单细胞、分裂、分化、器官形成和人体轮廓均为抽象粒子、发光网络、形态场、系统耦合的概念表达。项目强调“生命自组织与涌现”的宏观逻辑，而不是提供实现生命体构建的技术方法。

## 建议用途

- 科普视频脚本预演；
- 系统生物学/发育生物学课程展示；
- 安全的合成生物学伦理传播；
- 3D 科学可视化原型。
