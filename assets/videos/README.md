# 视频资产说明

本目录用于存放《从单细胞到人类：生命体自组织的三维演化》的视频输出。

已包含：

- `cell_combination_human_concept.svg`：轻量级动画 SVG，可直接在浏览器中预览。

本地运行脚本后会生成：

- `cell_combination_human_concept.mp4`
- `cell_combination_human_concept.gif`

生成命令：

```bash
python scripts/render_concept_video.py
```

说明：视频采用抽象粒子、细胞膜、分化色带、器官网络和人形轮廓表达生命系统的自组织过程，不包含任何真实实验参数或可操作生物工程信息。
